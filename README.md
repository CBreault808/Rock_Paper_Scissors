# Rock Paper Scissors

## Code Overview

The program starts by welcoming the user to a Bash Battle and then prompting them to choose between Rock, Paper, or Scissors. Each choice is assigned to 1, 2, and 3 respectively. The program will then generate a random choice for the computer using the same options. 


The game determines the winner using classic rules:

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choice = Tie

The program also color codes the outcomes of each battle:

* Green = Wins
* Yellow = Tie
* Red = Loss

Some added features the game includes:

* Trash-talking computer
* Statistics such as total games, # of wins and losses, and win percentage
* Secret Mode options such as Lizard and Spock


To make the script executable in a Linux shell, use the command `chmod +x rps.sh`
